# TAALBOUND v0.1 — Browser Prototype

A lightweight HTML5 Canvas prototype for TAALBOUND.

## Controls
- Android: tap the game screen to jump
- PC: Space or Up Arrow to jump
- Start/Restart buttons work with touch or mouse

## v0.1
- Auto-running player
- Jump physics
- Ground
- Spikes
- Horizontal scrolling
- Camera-style world movement
- Progress percentage
- Death/restart
- Futuristic placeholder visual layer
